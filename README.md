# GRE Quant 고난도 실전 모의고사 (20회)

GRE General Test **Quantitative Reasoning** 실전 모의고사 20회분과 **문항별 한국어 단계별 해설·오답 분석**을 제공하는 정적 웹 앱입니다.
[GRE Verbal 모의고사](https://github.com/ByeongjunPark/gre)와 같은 구성(ETS 스타일 시험 화면, 오답노트, 성적 기록)을 따릅니다.

## ✨ 주요 기능

1. **현행 GRE 규격 (2023년 9월 이후 단축형 시험)**
   - Section 1: 12문항 / 21분 · Section 2: 15문항 / 26분 → 총 27문항, 47분
   - 회차별 구성: QC 8 · 단일 정답 MC 8 · 복수 정답(Select all) 2 · Numeric Entry 6 · Data Interpretation 1세트(3문항)
   - 섹션마다 QC가 앞쪽에 나오고, 산술·대수·기하·자료 분석을 고르게 배치합니다.
2. **ETS(PowerPrep) 스타일 시험 화면**
   - 상단 헤더(Section X of 2, Question X of Y, Time Remaining, Hide Time)
   - Review(응답·표시 상태 확인 후 이동), Mark, Help, Exit Section, Quit Test
   - **온스크린 계산기**: 연산 순서 적용, √, 메모리(MR/MC/M+), 괄호, Numeric Entry용 *Transfer Display*, 드래그 이동
   - Numeric Entry는 정수·소수 한 칸 / 분수 두 칸 입력(동치 분수 인정)
   - 실전 모드(시간 제한) / 연습 모드(무제한)
3. **결과 화면 & 오답노트**
   - 추정 점수(130–170, 원점수 비례 추정치), 섹션·유형·영역별 정답률
   - [전체 / 오답노트만 / 맞힌 문항] + 유형별 필터, 인쇄·PDF 저장
   - **🎯 내가 고른 답이 틀린 이유**: 고른 오답(또는 입력한 숫자)이 어떤 함정에서 나온 값인지 문항별로 분석
   - **💡 핵심 아이디어 + 🪜 단계별 풀이 + 선택지별 분석** (한국어)
   - **📖 이 문제의 수학 용어**: 문항에 나온 영어 수학 표현(예: remainder, inscribed, without replacement, interquartile range)과 한글 뜻
   - **[수학 용어집](glossary.html)**: 140여 개 GRE 수학 표현을 영역별로 정리, 영어·한글 검색, 20회 전체 등장 횟수 표시
4. **성적 기록**: 응시 기록이 브라우저 localStorage에 저장되며, 메인 화면에 회차별 최고 점수·영역별 약점을 표시합니다(JSON 내보내기/가져오기 지원).

## 📐 난이도와 출제 범위

GRE Quant 기준 **상위권(160–170) 대비용 고난도 문항** 위주입니다. 범위는 GRE General의 고교 수준 수학으로 한정했고, 미적분이나 선형대수 같은 이공계 수학은 다루지 않습니다.
아래와 같은 GRE 고난도 단골 주제를 다룹니다.

| 영역 | 대표 주제 |
| --- | --- |
| 산술 | 나머지 조건 2개와 LCM 주기, 조건부 약수의 개수, n!의 소인수 지수, 일의 자리·순환소수 주기, GCD·LCM 가능한 값, 연속 백분율·복리 vs 단리, 연쇄 비율 |
| 대수 | Vieta, 대칭형 연립방정식, 절댓값 부등식의 정수해, 새 연산 정의, 점화식 역추적, 지수방정식, 일률·농도(치환 반복)·조화평균 속력, 원형 트랙, 부호 분석 QC |
| 기하 (그림 포함) | 평행선과 꺾인 선의 각, 원주각·중심각, 색칠한 영역(사분원·렌즈·반원), 이등변삼각형 연쇄(틱 표시), 좌표평면 위 삼각형, 직각삼각형의 높이(닮음), 변과 각의 대소(축척 아님), 등변사다리꼴, 활꼴·원과 정사각형, 닮음비와 넓이비, 둔각삼각형이 되는 정수 변, 직육면체 세 면의 넓이 |
| 자료 분석 | “적어도” 조합(중복 계산 함정), 이웃·순서 조건 순열, 비복원 추출, 독립 시행, 같은 것이 있는 순열, 평균·중앙값 조건 최댓값, 정규분포(68–95), 가중평균, 도수분포표 사분위수, 세 집합 벤다이어그램, 격자 경로, 표 해석(DI) |

## 🧮 문항은 어떻게 만들었나요?

- **모든 문항은 이 저장소의 생성기(`gen/`)로 직접 만든 창작 문항**입니다. 저작권 문제로 ETS 공식 문항이나 시판 교재·사이트 문항은 가져오지 않았습니다.
- 81개 문항 템플릿이 숫자를 바꿔 문항을 만들고, **정답은 코드가 직접 계산**합니다. 대부분 전수 탐색(brute force)이나 정확한 분수 연산(`Frac`)을 씁니다.
- 변수가 있는 QC는 조건 구간 전체를 촘촘히 샘플링해 (A)/(B)/(C)/(D)를 판정합니다. (D)인 문항의 해설에는 관계가 뒤집히는 구체적 반례를 넣었습니다.
- **기하 그림**은 `gen/fig.js`가 실제 좌표로 계산해 SVG로 그립니다(축척대로가 아닌 그림에는 GRE처럼 *Note: Figure not drawn to scale.* 표시). 모든 섹션에 그림 문항이 2개 이상, 회차당 4–6개 들어갑니다.
- 오답 보기는 대부분 **실제로 자주 하는 실수에서 나오는 값**(예: 산술평균 속력, 중복 계산된 조합, 닮음비를 그대로 넓이비로 쓴 값)입니다. 해설에 그 이유를 적었습니다.
- 같은 유형(템플릿)이 여러 회차에 숫자만 바뀌어 다시 나옵니다(템플릿당 약 4–8회). 반복 연습용으로 의도한 설계입니다.

## 🚀 실행 방법

빌드 없이 정적 파일만으로 동작합니다. `index.html`을 브라우저에서 바로 열어도 되고, 로컬 서버를 띄워도 됩니다.

```sh
python -m http.server 8000   # 또는: npx serve .
# http://localhost:8000/
```

GitHub Pages: 저장소 Settings → Pages → Branch `main` / `(root)`로 설정하면 `https://<user>.github.io/gre_quant/`에서 열립니다.

## 🔧 문항 다시 생성하기 / 검증

```sh
node gen/verify.js 300   # 모든 템플릿×형식을 300회씩 생성해 구조·정답·중복 보기 검사
node gen/build.js        # Quant_Mock_01~20.html, js/quant_explanations_XX.js 재생성 (시드 고정 → 결과 동일)
node gen/print_test.js 5 # 5회 문항·정답·풀이를 텍스트로 출력 (검토용)
```

| 경로 | 설명 |
| --- | --- |
| `gen/lib.js` | 난수(시드 고정), 분수 연산, 표기 도우미, QC 판정기 |
| `gen/t_arith.js` `t_alg.js` `t_geo.js` `t_data.js` `t_qc.js` `t_di.js` | 영역별 문항 템플릿 (한국어 해설 포함) |
| `gen/fig.js`, `gen/t_fig.js` | 기하 그림(SVG) 도우미와 그림 기반 기하 문항 |
| `gen/glossary.js`, `gen/glossary_page.js` | 수학 용어 사전(영어 → 한글)과 문항별 용어 추출, 용어집 페이지 생성 |
| `gen/make.js` | 템플릿 결과를 QC / MC / MA / NE 문항과 해설 데이터로 변환 |
| `gen/build.js` | 회차 구성(형식·영역 균형, 템플릿 사용 횟수 균등화) 및 파일 출력 |
| `js/quant_exam.js` | 시험 엔진(화면, 타이머, 계산기, 채점, 결과·해설) |
| `js/quant_history_manager.js` | 응시 기록(localStorage) |
| `css/ets_gre_exam.css`, `css/explanation.css` | Verbal 저장소와 같은 ETS 테마 / 해설 스타일 |
| `css/quant.css` | Quant 전용 스타일(QC 표, Numeric Entry, 계산기, 결과 화면) |

## ⚠️ 참고

- 실제 GRE는 섹션 단위 적응형(Section 1 결과에 따라 Section 2 난이도 결정)입니다. 이 모의고사는 두 섹션 모두 고난도로 고정했습니다.
- 130–170 점수는 원점수 비례 추정치이며 ETS 공식 환산이 아닙니다.
- GRE®는 ETS의 등록상표이며, 이 프로젝트는 ETS와 관련이 없습니다.
